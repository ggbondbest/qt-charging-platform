# 全量数据集实际统计快照

数据批次：`charging_full_180d_v1`，来源 **SIMULATED**，随机种子 `20260912`。业务日期为 **2025-12-01 至 2026-05-29**（含首尾，共 180 天，`Asia/Shanghai`）。这是教学模拟经营数据，不是五个城市的真实运营报告。

本页依据 [全量校验报告](../datasets/charging_full_180d_v1/validation_report.json)、[manifest](../datasets/charging_full_180d_v1/manifest.json) 与 `reference_aggregates/station_daily`、`station_hourly` 计算。参考汇总由 **Python 模拟器**产生，用于后续核对，**不是 Spark 已运行的计算结果**。

## 1. 数据规模与种类

## 2. 五城市经营与利用率

| 城市 | 交付电量（kWh） | 净收款（元） | 充电时间利用率 |
| --- | ---: | ---: | ---: |
| 大连市 | 739,284.481 | 850,983.16 | 37.43% |
| 沈阳市 | 770,090.802 | 921,346.88 | 39.40% |
| 北京市 | 824,164.000 | 1,026,240.83 | 41.75% |
| 上海市 | 849,196.108 | 1,097,506.25 | 42.80% |
| 深圳市 | 892,149.456 | 1,192,264.89 | 44.46% |
| **合计** | **4,074,884.847** | **5,088,342.01** | **41.17%** |

口径：电量按遥测发生时间汇总；净收款 = 期间成功 `PAYMENT` − 成功 `REFUND`，不是利润；利用率 = `CHARGING` 区间数 ÷ 全部在役计划区间数。每城 15 桩 × 180 天 × 288 区间 = 777,600 个区间，且本批遥测完整。城市差异源于模拟参数与随机过程，不能解读为真实城市优劣。

按模拟分时价格，谷段交付电量 **621,440.590 kWh（15.25%）**、平段 **2,082,312.233 kWh（51.10%）**、峰段 **1,371,132.024 kWh（33.65%）**。谷段是本地 00:00–07:00；峰段为 10:00–12:00、18:00–22:00，其余为平段，不代表真实地区电价政策。

典型差异：社区类型充电时间利用率 **53.44%**、交付电量 **600,946.186 kWh**；交通枢纽类型利用率 **48.88%**、电量 **1,113,830.290 kWh**。社区配置更多低功率 AC，说明“占用充电时间多”不必然“交付电量多”；这是配置与过程共同产生的模拟结果，不是因果实验。

## 3. 业务和异常场景覆盖

- **排队**：35,854 次；成功叫号转入会话 21,892 次（61.06%），等待中退出 10,110 次，叫号未确认 3,852 次。25,744 次已叫号样本平均等待 **16.82 分钟**，P95 **40 分钟**（nearest-rank）；未叫号就退出的用户不混入这个等待均值。
- **预约与支付**：预约确认 16,301 次、主动取消 2,019 次、过期 1,618 次。有效会话中 125,929 条已支付完成、3,839 条待支付；支付失败事件 15,062 条，退款事件 3,206 条。支付重试不是充电启动重试。
- **维护**：417 张工单全部已恢复，涵盖连接器 114、通信 104、冷却 107、功率模块 92；遥测含 12,216 个维护区间及 4,121 个离线区间。本批没有期末未解决工单，不应展示虚构积压。
- **停止与算法样本**：目标达成 120,475 次、时长上限 7,307 次、用户提前停止 1,986 次。异常标签为降功率 1,882、提前停止 1,986、温升 1,358。故障只在空闲资源上自动发现，未模拟充电中断或温度保护断电；所有目标模式均为 `ENERGY`。
- **丰富分组**：5 种站点类型、4 种用户分群、4 种支付渠道、1–5 星评价，以及晴/雨/雪天气均有样本；这些维度可做统计，不表示已经训练模型或验证真实商业规律。

完整字段、统计口径和模型使用限制见 [运营指标说明](operator_metrics.md)。展示清洗过程时应从原始层运行任务，再与本页及 Python 对照结果核验，不能把已有对照文件重新命名为 Spark 产物。
