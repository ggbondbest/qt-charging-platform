# 到站状态与等待模型

本模块实际训练 CPU HistGradientBoosting：0–3 空闲桩分类分布、非预约成功充电条件下平均等待/P90、非预约请求服务成功概率。输入为已清洗的 180 天模拟数据，分辨率 **5 分钟**，不代表真实运营验证。

```bash
python -m data_analysis.chargepilot.ml.train --output data_analysis/outputs/chargepilot --threads 2
python -m unittest data_analysis.tests.test_chargepilot_ml -v
```

训练命令读取全部 CLEAN Parquet 分片，核对每桩每时刻恰好一条 300 秒遥测和容量守恒，再生成固定随机种子的有界训练样本。默认 TRAIN 160,000 行，VALIDATION / TEST 各 35,000 行；等待任务从实际请求构造多个提前量，同一请求的副本不跨时间切分，不计成独立用户。没有下载外部数据或使用 GPU。

沿用交付 manifest 的上海时区边界：训练 `[2025-12-02,2026-03-30)`，验证 `[2026-03-30,2026-04-29)`，测试 `[2026-04-29,2026-05-29)`。预测起点、到达、标签完成时刻均需在同一切分内，首尾业务日与跨界目标剔除。概率温度参数只在 VALIDATION 拟合；TEST 不用于模型选择。完整来源分片 SHA-256、批次、环境版本、参数、样本量与实际指标保存在 `arrival.metadata.json`。

模拟器在新请求处理后写同刻遥测，因此起点 `t` 必须取 `t−5min` 的完整区间及更早窗口。特征生成和在线预测使用同一 `Replay.features`，不读取未来实际天气、会话结束/费用/离场时刻、目标到访队列位置、异常或污染标签。预约计划延迟不混入普通等待；未成功请求的服务等待保留缺失，不填零。

到达 `00:12:42` 对应 `00:10–00:15` 状态时间槽，响应同时提供精确到达与 `forecastTime=00:10`。`currentFree` 是出发前完整采样。`expectedFree` 是分类分布的数学期望，可以为小数；`availableProbability=1−P(0)`。等待是成功获得服务的条件平均值，不能解释成包括失败用户的无条件保证。

2026-09-14 实际固定配方结果（全部为模拟数据 TEST）：

| 指标 | 模型 | 基线 |
| --- | ---: | ---: |
| 空闲数 MAE / 桩 | 0.39261 | 持久状态 0.38960 |
| 空闲数 RMSE / 桩 | 0.58848 | 持久状态 0.73504 |
| 至少一桩可用 Brier | 0.08364 | 持久状态 0.14200 |
| 条件等待 MAE / 分钟 | 4.61767 | 永远零等待 4.05475 |
| 条件等待 RMSE / 分钟 | 7.80222 | 永远零等待 10.31598 |
| 条件等待 MAE / 分钟 | 4.61767 | TRAIN 站点×小时均值 5.98041 |
| 服务成功 Brier | 0.15491 | TRAIN 成功率常数 0.20196 |

模型的期望空闲数 MAE 略逊持久状态，平均等待 MAE 也逊零等待；其 RMSE、概率与历史均值比较更好，不能描述为全面胜过基线。等待 TEST 25,205 个成功提前量样本，P90 上界覆盖率 93.47%；服务成功 AUC 0.79663。第一次执行约19秒，增加来源绑定与修复概率基线归一化后同种子重建约16秒，未据 TEST 调参，模型指标保持一致。

产物位于忽略的 `outputs/chargepilot`：可信本机 `arrival.joblib`、来源与指标 `arrival.metadata.json`、压缩完整状态 `replay.npz`、目录/日历/电价 `replay.json`。加载前核对 scikit-learn 精确版本及文件哈希，模型/缓存/元数据同时绑定 CLEAN 来源。此处不接受用户上传 pickle。

目录的 `powerKw` 是为了三桩运营演示采用的 **站点总功率÷容量** 虚拟均分桩功率，`ratedCapacityKw` 保留总功率；它不是原始每个 AC/DC 桩的实测功率。模型负荷特征和归一化仍用站点总功率。

`ArrivalPredictor.actual()` 只供离线仿真读取同期状态与未来首次空闲，不可用于推荐特征；`predict()` 和 `snapshot()` 完全独立于该入口。策略仿真还须独立维护自身分配的资源占用，不能把背景未来状态当作模型预测。
