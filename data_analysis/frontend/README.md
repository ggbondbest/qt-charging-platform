# 充能智析 · 统一 Vue 网页

Vue 3 + TypeScript + Vite + ECharts + Leaflet，需要 Node.js ≥ 23。

```bash
cd data_analysis/frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 请求代理到 `http://127.0.0.1:8000`；后端改用统一入口 `python -m data_analysis.delivery.cli serve`，配置见 `../delivery/README.md`。生产构建输出到忽略的 `dist/`，由同一 FastAPI 服务提供网页和 API，不需要第二个前端或 iframe。

```bash
npm run build
npm test
```

## 一个入口，五个分区

| 页面 | 实际数据与功能 |
| --- | --- |
| 当前模拟业务（默认） | 合并原生运营概览：今日/本月/累计营收、在线率、用户数、订单与电量、7/30 日趋势、异常电桩、站点状态和最近订单 |
| 历史运营分析 | 已发布 MySQL 模拟批次的城市/日期筛选、充电量、收退款、利用率、活跃/复充用户、地理分布、城市贡献、站点排名、小时负荷、排队、维修/评价、清洗质量与血缘 |
| 智能找站实验 | ChargePilot 独立回放场景的地图起点、分钟到站空闲/等待预测、六项评分解释、小时负荷辅助均衡、推荐积分标签与路线预览；不触发 Qt 预约 |
| 智能分析 | 单一负荷/小时末空闲预测工作台；用户回访风险、已结束会话异常筛查；真实评价与配对实验 |
| 模拟控制台 | 进入后自动加载模拟时钟与最近站/智能推荐配对实验，无管理员令牌输入 |

## 数据与交互约束

- 默认当前模拟业务不调用 ChargePilot `/bootstrap`，历史分析/模型数据库未就绪也能展示 Qt 快照。仅进入找站实验、智能分析或模拟控制台时才初始化回放业务。
- Qt 分区只请求 `GET /api/v1/qt-live/snapshot?orderLimit=20&stationLimit=500&trendDays=7`（趋势可选 30 天），保证指标、趋势、异常、站点和订单使用同一后端读取事务。只接受 `dataSource=qt-sqlite`、`scope=CURRENT_QT_BUSINESS`、`mergedWithHistory=false`、`simulated=true` 的响应。
- Qt 快照完成后 7.5 秒再次轮询，请求超时 6 秒；切页/窗口隐藏时取消在途请求并暂停，返回时立即刷新。失败明确提示离线并保留最后成功 `asOf`，首次失败显示 `—`。仅 COMPLETED 订单计入已完成订单金额和电量，所有数据不与历史 MySQL 合并。
- 当前业务的营收、完成订单和电量按北京时间支付日期归属，今日新增订单按创建日期统计。在线率为非 OFFLINE 电桩占比（含 FAULT），不表示可用率。趋势严格校验日期序列和零填充，异常摘要最多展示 5 根，不显示用户隐私或自由文本日志。
- 运营统计读取 `/api/v1/datasets`、`cities`、`stations`、`dashboard/*`、`pipeline/runs`。每次查询固定 `datasetId + publishedBatchId`；任一响应不一致则拒绝展示。全部图表完成才呈现新结果。
- 日期按北京时间，`endDate` 不含当天，默认最近 7 个业务日。质量指标属于整个批次；设备状态是批次最新快照，不冒称实时。
- 金额分转为元，电量 Wh 转为 kWh；功率 kW 独立作图。未知/缺测保留空值与断点，不替换成零。
- 模型目录来自 `/api/v1/intelligence/models`，预测调用 `POST /api/v1/intelligence/forecast`。负荷点为小时均值，空闲点为小时末 `hh:55` 库存，后者不替代智能找站的分钟 ETA 模型。
- 回访风险分数未经概率校准，不标为流失百分比。异常筛查只对已结束会话辅助复核；展示留出评价和低召回限制，不自动冻结用户、停桩或发券。
- 异步请求有超时、取消、序号保护；筛选/预测目标变化后不显示过期结果。离开页面清理地图与观察器。

首次推荐时建立访问会话，token 存入本机 localStorage，供推荐与路线接口鉴权。模拟控制台进入时自动查询 `/admin`，不发送管理员令牌；回放时钟和实验操作继续使用原有接口。网页不提供行程、充电、支付或积分操作，推荐卡片保留后端返回的积分标签。

全站明确标记模拟数据，时间按 Asia/Shanghai 展示。找站/分析/控制台每 2 秒读取回放站点和必要的实验进度，不再查询当前行程；隐藏页面、Qt 分区或历史统计页暂停，卸载时清理定时器。有效推荐到期后在找站页自动重新计算。后台配对实验返回 RUNNING 时继续等待实际报告。AI 参谋仅在历史分区提供，来源为已发布历史聚合、知识库和模型报告，不读取 Qt 当前业务。

地图使用 OpenStreetMap 标准瓦片并保留署名。瓦片尚未加载或不可达时，立即显示可交互的经纬位置示意；虚线只是直线距离，不冒充道路。推荐卡片通过 `/route` 获取路线，不调用选站创建行程接口；腾讯服务降级时明确标注直线示意。切换起点、城市、需求、推荐结果或页面会取消旧路线请求。字体使用设备本地可用字体，离线时不会阻止页面渲染。

模型指标只显示后端返回的实际结果；TEST 与验证集记录分别保留。条件等待只对成功的非预约样本评估，零等待基线与模型 MAE 同时展示。实验表中的资源占用率包括保留/离线/维护等不可用资源，不等同于实际充电利用率。

## 关键文件与验收

- `src/App.vue`：Qt/历史分区导航、嵌入模式、找站与实验控制台。
- `src/components/QtLivePanel.vue`、`src/qtLiveApi.ts`、`src/qtLiveMonitor.ts`：Qt 快照、契约验证、可暂停轮询与离线状态。
- `src/components/OriginPicker.vue`、`RecommendationRoute.vue`：起点设置与独立路线预览。
- `src/routePreview.ts`：路线请求取消与过期响应隔离。
- `components/AnalyticsDashboard.vue`：真实历史统计。
- `components/ForecastPanel.vue`：负荷/小时空闲工作台。
- `components/ManagementInsights.vue`：用户与会话风险。
- `analytics.ts`、`forecast.ts`：发布契约、单位、时区与模型选择。
- `api.ts`：智能找站业务请求与安全错误。
- `analytics.test.ts`、`api.test.ts`、`display.test.ts`：契约、单位、时间、取消及显示回归。

验收流程：总览切城市/日期 → 分别预测负荷/空闲 → 查用户风险与异常会话输入事实 → 设置起点并推荐 → 查看积分标签、推荐依据与路线 → 控制台运行配对实验并跳转结果。智能找站契约仍见 `../chargepilot/CONTRACT.md`；后端兼容业务接口、已有记录与一期 Qt TCP 不受影响。

## Qt 管理端嵌入

管理端打开统一服务的 `/?embedded=operator`（自动服务使用动态本机端口，独立启动器默认 8000）。运营中心默认显示当前模拟业务，历史运营分析保留独立标签。嵌入模式保留紧凑导航，隐藏重复品牌、标题和页脚，内容铺满 Qt 可用区域并自行滚动。无需启动 Vite 开发服务器。

嵌入模式的 AI 参谋放在顶部分区导航中，避免浮动角色挡住预测、筛查按钮和图表；对话按需展开，Esc 收起并返回入口。网页独立打开时保留原有悬浮角色。窄窗口的分区按钮可横向滚动，助手入口保持可见。

当前业务与历史分析都提供「大屏模式」，通过标准 `requestFullscreen()` 进入真正全屏，退出按钮或 Esc 恢复窗口；状态由 `fullscreenchange` 同步。请求被拒绝时显示错误，不会仅切换 CSS 冒充全屏。Qt WebEngine 由原生页面处理全屏请求并隐藏、恢复窗口导航。

构建语法与 CSS 目标设为 `chrome87`，配合 Qt 6.2 WebEngine；参谋导航避免调用该内核不支持的 `Object.hasOwn`，历史 API 用查询字符串判空，避免 `URLSearchParams.size` 缺失导致筛选与分页参数丢失。构建和单元测试通过不代表所有平台的 WebEngine 已验证。目标机器仍需在 1024×720 窗口检查图表、地图、请求、滚动与失联提示；无法稳定嵌入时使用 Qt 页内的系统浏览器入口。

Qt 联调验收：同一 SQLite 路径启动 Qt Server 与适配服务 → 打开当前模拟业务 → 在 Qt 中预约/充电/完成支付 → 核对快照中同站点、订单状态、分/Wh 单位和累计口径 → 暂停适配服务确认最后成功时间不改变 → 恢复服务确认自动更新 → 停用 MySQL 验证 Qt 分区仍可用。
