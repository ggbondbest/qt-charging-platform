# 充能智析 · 统一 Vue 网页

Vue 3 + TypeScript + Vite + ECharts + Leaflet，需要 Node.js ≥ 23。

```bash
cd data_analysis/frontend
npm ci
npm run dev
```

打开 `http://127.0.0.1:5173`。Vite 将 `/api` 请求代理到 `http://127.0.0.1:8000`；后端改用统一入口 `python -m data_analysis.delivery.cli serve`，配置见 `../delivery/README.md`。生产构建输出到忽略的 `dist/`，由同一 FastAPI 服务提供网页和 API，不需要第二个前端或 iframe。

```bash
npm run build
npm test
```

## 一个入口，四个页面

| 页面 | 实际数据与功能 |
| --- | --- |
| 运营总览 | 城市/日期筛选、充电量、收退款、利用率、活跃/复充用户、地理分布、城市贡献、站点排名、小时负荷、排队、维修/评价、清洗质量与血缘 |
| 智能找站 | 地图起点、分钟到站空闲/等待预测、六项评分解释、小时负荷辅助均衡、推荐积分标签与路线预览 |
| 智能分析 | 单一负荷/小时末空闲预测工作台；用户回访风险、已结束会话异常筛查；真实评价与配对实验 |
| 模拟控制台 | 管理员验证、模拟时钟与最近站/智能推荐配对实验 |

原 PR72 未使用的固定统计、假预测、车型积分彩蛋、重复 JS 入口与样式文件已移除。不会出现“连接成功但图表仍使用固定示例”的路径。

## 数据与交互约束

- 运营统计读取 `/api/v1/datasets`、`cities`、`stations`、`dashboard/*`、`pipeline/runs`。每次查询固定 `datasetId + publishedBatchId`；任一响应不一致则拒绝展示。全部图表完成才呈现新结果。
- 日期按北京时间，`endDate` 不含当天，默认最近 7 个业务日。质量指标属于整个批次；设备状态是批次最新快照，不冒称实时。
- 金额分转为元，电量 Wh 转为 kWh；功率 kW 独立作图。未知/缺测保留空值与断点，不替换成零。
- 模型目录来自 `/api/v1/intelligence/models`，预测调用 `POST /api/v1/intelligence/forecast`。负荷点为小时均值，空闲点为小时末 `hh:55` 库存，后者不替代智能找站的分钟 ETA 模型。
- 回访风险分数未经概率校准，不标为流失百分比。异常筛查只对已结束会话辅助复核；展示留出评价和低召回限制，不自动冻结用户、停桩或发券。
- 异步请求有超时、取消、序号保护；筛选/预测目标变化后不显示过期结果。离开页面清理地图与观察器。

首次推荐时建立访问会话，token 存入本机 localStorage，供推荐与路线接口鉴权。管理员令牌由操作者输入，只存当前页面内存；没有预置密钥。网页不再提供行程、充电、支付或积分操作，推荐卡片保留后端返回的积分标签。

全站明确标记模拟数据，时间按 Asia/Shanghai 展示。找站/分析/控制台每 2 秒读取站点和必要的实验进度，不再查询当前行程；隐藏页面或统计页暂停，卸载时清理定时器。有效推荐到期后在找站页自动重新计算。后台配对实验返回 RUNNING 时继续等待实际报告。

地图使用 OpenStreetMap 标准瓦片并保留署名。瓦片尚未加载或不可达时，立即显示可交互的经纬位置示意；虚线只是直线距离，不冒充道路。推荐卡片通过 `/route` 获取路线，不调用选站创建行程接口；腾讯服务降级时明确标注直线示意。切换起点、城市、需求、推荐结果或页面会取消旧路线请求。字体使用设备本地可用字体，离线时不会阻止页面渲染。

模型指标只显示后端返回的实际结果；TEST 与验证集记录分别保留。条件等待只对成功的非预约样本评估，零等待基线与模型 MAE 同时展示。实验表中的资源占用率包括保留/离线/维护等不可用资源，不等同于实际充电利用率。

## 关键文件与验收

- `src/App.vue`：统一导航、找站与实验控制台。
- `src/components/OriginPicker.vue`、`RecommendationRoute.vue`：起点设置与独立路线预览。
- `src/routePreview.ts`：路线请求取消与过期响应隔离。
- `components/AnalyticsDashboard.vue`：真实历史统计。
- `components/ForecastPanel.vue`：负荷/小时空闲工作台。
- `components/ManagementInsights.vue`：用户与会话风险。
- `analytics.ts`、`forecast.ts`：发布契约、单位、时区与模型选择。
- `api.ts`：智能找站业务请求与安全错误。
- `analytics.test.ts`、`api.test.ts`、`display.test.ts`：契约、单位、时间、取消及显示回归。

验收流程：总览切城市/日期 → 分别预测负荷/空闲 → 查用户风险与异常会话输入事实 → 设置起点并推荐 → 查看积分标签、推荐依据与路线 → 控制台运行配对实验并跳转结果。智能找站契约仍见 `../chargepilot/CONTRACT.md`；后端兼容业务接口、已有记录与一期 Qt TCP 不受影响。
