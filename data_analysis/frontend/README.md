# Vue 大屏：后续开发入口

当前仅搭目录和数据对接说明，没有伪造已实现的网页工程。
后续采用 Vue 3 + ECharts，通过 `backend/` 的 HTTP API 接入已完成的统计批次。

建议三页：

1. 智慧大屏：五城市筛选、站点地图、电量/净收款/可服务率、负荷趋势、站点排行。
2. 运营及数据质量：排队与到访结局、预约、维修时间轴、费用、评分、Spark 清洗报告。
3. 模型预测：输入站点/时间/跨度，展示预测曲线、模型版本、时间切分及测试指标。

页眉始终标注“模拟数据”、批次和统计时段；历史快照提供回放时间选择。
浏览器只取聚合数据，不下载原始百万行 CSV。preview 是看字段用的，不能冒充全量统计。
地图使用示意电站坐标，需遵守地图服务坐标系、署名和 Key 配置要求；密钥不能提交到仓库。
