# Vue 大屏：后续开发入口

当前仅搭目录和数据对接说明，没有伪造已实现的网页工程。
按验收采用 Node.js 23 及以上、Vue 3、DataV 大屏组件，可配合 ECharts 展示不同图表，通过 `backend/` 的 FastAPI 接入已完成的统计批次。

新增独立的 11 维/3 组双维分析输出与图表建议见 [清洗验收指南](../docs/cleaning_acceptance.md)。这些 CSV 和清单可供页面接入；不要把现有七类 chart 路由假定成支持全部新增维度。页面尚需开发和实测。

建议三页：

1. 智慧大屏：五城市筛选、站点地图、电量/净收款/充电利用率、小时负荷/电量/状态趋势、站点排行。
2. 运营及数据质量：排队结局、预约、维修耗时、费用、评分、Spark 清洗报告。
3. 模型预测：输入站点/时间/跨度，展示预测曲线、模型版本、时间切分及测试指标。

页眉始终标注“模拟数据”、批次和统计时段。日期选择过滤经营指标；站点状态是批次末快照，当前不提供历史状态回放。
浏览器只取聚合数据，不下载原始百万行 CSV。preview 是看字段用的，不能冒充全量统计。
地图使用示意电站坐标，需遵守地图服务坐标系、署名和 Key 配置要求；密钥不能提交到仓库。

接口和统计包已可用，先按 [数据层交付](../DATA_LAYER.md) 启动服务，再导入 [公共类型](../contracts/types.ts)。
所有字段以 [公共契约](../contracts/README.md) 为准；`examples/` 是实际接口响应。当前预测返回 MODEL_NOT_READY，等模型组交付后接入真实结果。
小时负荷使用 `chart=load&granularity=hour`；`meanPowerKw` 是所选站点平均功率的总和，有站点缺观测则返回 null。
API 尚未提供单票维修时间轴或到访请求失败细分的独立路由；若需要这些额外页面，应先扩展契约，不能把不相同的已有指标换个名称代用。
