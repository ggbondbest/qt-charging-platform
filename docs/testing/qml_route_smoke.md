# QML 页面与资源冒烟

构建正式 `charging-client` 后运行：

```bash
bash scripts/verify_qml_routes.sh build/client/charging-client build/qml-route-shots
```

脚本逐一启动 18 条路由，检查内嵌 QML 资源、页面创建、运行错误及截图生成；单页超过 20 秒即失败。日志和 420×860 截图保存在指定目录，需人工查看截图确认文字、按钮和滚动区域没有裁切或重叠。Qt 运行依赖必须先安装完整；脚本不包含机器专用依赖路径。

本测试**强制使用显式 Mock 通道，仅验证页面加载和布局**，不替代真实 TCP/SQLite、计费支付、会话隔离和业务状态机验收。地图密钥在测试进程中清空，导航应显示未定位或缺少地图配置的明确提示，不能伪造导航路线。真实地图验收需另配置已授权的腾讯 WebService/JavaScript 地图密钥并手动完成地址定位及驾车、步行路线切换。

可在 CI 完整测试后调用相同命令，并保存输出目录作为构建产物。登录页以未登录状态加载；其他页使用截图夹具账户。登录后的假账户、路由参数和金额均仅属于截图夹具。
